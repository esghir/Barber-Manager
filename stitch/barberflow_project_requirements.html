Project Name: BarberFlow – Smart Queue & Performance SaaS for Barbershops Version 1.1 – Updated with planned additional features (March 2026) Core Modules & Features: 1. Guest Check-in via QR Code (Scan, Select Barber/Service, Ticket + Wait Time) 2. Real-time Queue & Notifications (Live updates, 5-min reminders, No-show logic) 3. Barber Selection & Load Balancing (Specific barber or next available) 4. Manager / Owner Dashboard (Performance metrics, Ratings, Comparison charts, Reports) 5. Basic Inventory / Supply Requests (Flag low-stock, Manager alerts) Planned Additional Features: - Online Pre-booking / Reservation (Phase 3) - Payment Integration (Phase 3) - Loyalty / Points System (Phase 2-3) - Barber Availability Calendar (Phase 2) - SMS Notifications (Phase 1-2) - Multiple Service Categories & Pricing (Phase 1) - Client Account / History (Phase 2) - No-Show / Cancellation Fee (Phase 3) - Multi-language Support (Phase 1) - Staff Roles & Permissions (Phase 2) - Daily / Weekly Shop Summary Email (Phase 2) - Integration with POS / Cash Register (Phase 3)
